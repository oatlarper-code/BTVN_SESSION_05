5. Yêu cầu đầu ra
+ Bản phác thảo sơ đồ luồng IPO của việc khởi tạo hạ tầng
+ Input: các lệnh tạo, sao lưu thư mục, file
+ Process: máy tính tiến hành thực thi các lệnh
+ Output: kết quả sau khi máy tính tạo thành công hoặc thất bại các thư mục, file
- Danh sách các câu lệnh Powershell đã sử dụng:
+ Tạo cây thư mục lồng nhau: Ví dụ: mkdir smart-farm\data\logs, smart-farm\code
+ Tạo cùng lúc 3 file cấu hình: Ví dụ: ni config.json, sensors.py, ok.env
+ Sao chép toàn bộ thư mục code sang backup\code_v1: Ví dụ: mv code backup\code_v1
