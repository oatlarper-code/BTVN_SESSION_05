4. Yêu cầu đầu ra
- Bản phác thảo sơ đồ luồng IPO:
+ Input: Nhập dữ liệu thô trong thư mục Download
+ Process: Xử lý các thông tin đuôi file để thực thi các lệnh
+ Output: Kết quả sau khi máy tính xử lý thành công các tệp tài liệu hoặc thư mục rác
- Danh sách câu lệnh kịch bản cho Robot:
+ Input: Ví dụ: "cd ~" để quay trở về ổ cứng chính sử dung dòng lệnh cd .\Downloads\ để tới thư mục Downloads
+ Process: Sau khi quét xong đuôi file Robot sẽ sử dụng lệnh “mv” để chuyển các file có đuôi tương ứng với thư mục như: media,... Ví dụ: mv *.png,*.jpg media; mv *.py scripts; rm *.tmp 
+ Output: Kết quả sẽ được trả trên máy tính cá nhân
